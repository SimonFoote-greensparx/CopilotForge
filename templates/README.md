# Templates

Human-usable document templates (design brief section 16). Each names the skill responsible for it, marks every fact
the organisation must supply as `[To confirm: ...]`, and ends with the CopilotForge credit line. Profile values populate
only facts supplied or derived through documented rules; unknowns stay visibly marked. The full rules are in
`docs/STYLE-GUIDE.md`, and `scripts/check-templates.py` enforces them.
