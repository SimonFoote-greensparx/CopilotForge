# Scale-or-stop review

Template id: `scale-or-stop-review`
Responsible skill: `opportunity-management:scale-or-stop`

Use this template at the review date agreed when the pilot or first release began. Judge the evidence against the
thresholds set beforehand; never set or change a threshold after seeing the results. Adoption evidence is reported at
team or role level only.
