# CopilotForge

**Your Microsoft AI transformation team, as installable AI skills.** Website: https://copilotforge.ai/

CopilotForge is an open-source library of specialised AI skills, programmes, templates and delivery patterns that
together model the team and operating capability an organisation needs to go from "we want to use AI" to "we have a
governed, measurable and sustainable Microsoft AI capability".

It is organised around three connected journeys:

| Journey | Purpose |
|---|---|
| **Adopt AI** | Enable people to use Microsoft Copilot effectively and responsibly: readiness, role-based scenarios, Champions, support and adoption measures. |
| **Build with AI** | Design and deliver agents, Cowork work designs, Copilot Code builds, Copilot Studio and Microsoft Foundry solutions. |
| **Scale AI** | Establish governance, an AI Centre of Excellence, an opportunity portfolio, review gates and measurable value. |

> **Status: draft (v0.2).** First versions of all 27 departments in the target design now exist, with first-draft
> skills, programmes and templates. Every skill is `status: draft` until reviewed. See [ROADMAP.md](ROADMAP.md).

## Scope

CopilotForge covers Microsoft AI only: Copilot Chat and Microsoft 365 Copilot, agents, Copilot Cowork, Copilot Code,
Copilot Studio, Microsoft Foundry (including third-party models available through Microsoft), Power Platform automation
and the Microsoft governance stack (decision D22).

## The flagship request

Give CopilotForge an organisation profile and ask: *"Design our Microsoft AI programme."* It recommends an edition and
maturity archetype with the rule that produced each, then orchestrates the departments to produce a coherent
transformation pack: assessment, operating model, adoption programme, Champions programme, CoE, opportunity process,
agent-delivery model, governance framework, roadmap, ownership map, templates and success measures.

```
python3 scripts/tailor.py profiles/samples/larkfield-services-scale.yaml
```

shows the deterministic plan behind the pack for a fictional 600-person organisation.

## Use it in Microsoft Copilot Cowork

Download a department archive from [`cowork/plugins/`](cowork/plugins/) and upload it in Copilot Cowork under
**Customize** > **Plugins** > **Upload plugin**. The guide is [docs/COPILOT-COWORK.md](docs/COPILOT-COWORK.md).

## Repository map

| Path | What it holds |
|---|---|
| `departments/`, `reviewers/` | Skills, one folder per department. Reviewer-class departments, which may block, live in `reviewers/`. |
| `programmes/` | Flagship programmes that orchestrate skills into complete outcomes. |
| `editions/`, `archetypes/` | Starter, Scale and Enterprise overlays, and the five maturity archetypes. |
| `profiles/` | The organisation profile schema and fictional samples. |
| `templates/` | Human-usable document templates. |
| `sources/` | Structured source records for volatile product facts. |
| `scenarios/`, `evaluations/`, `tests/` | Cross-department scenarios, golden outputs and acceptance cases, trigger and reviewer tests. |
| `catalogue/`, `data/`, `schemas/` | The department catalogue, tailoring rules and JSON schemas. |
| `scripts/` | Generators and checks. `bash scripts/build-all.sh` regenerates and checks everything. |
| `cowork/` | Generated Copilot Cowork plugin archives and suggested custom instructions. |
| `site/` | The website's core pages and assets. `python3 scripts/build-hosting.py` builds the full site for https://copilotforge.ai/ (see [docs/HOSTING.md](docs/HOSTING.md)). |

Maintainers (human or AI) start with [COWORK.md](COWORK.md), then [ARCHITECTURE.md](ARCHITECTURE.md) and
[DECISIONS.md](DECISIONS.md).
