# Website

The public CopilotForge website will be generated from this repository (decision D14) so that product, documentation
and catalogue cannot drift: home ("Build your Microsoft AI capability."), an interactive capability map organised as
Strategy, Adopt, Build, Govern, Scale and Measure, programme pages, the template library, worked examples, source
freshness and a browser-local programme builder that writes a profile valid against `profiles/schema.json`. Its data
feed is `catalogue/catalogue.json`. Hosting and domain are open decision O1. Built in phase 6.
