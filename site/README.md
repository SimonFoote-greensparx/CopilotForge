# Website

The CopilotForge website for https://copilotforge.ai/ is generated from this repository (decision D14).

- `*.html` here are generated by `scripts/build-site.py`: home, capabilities catalogue, programmes, templates,
  programme builder, author, contributors and privacy. Never edit them by hand.
- `assets/site.css`, `assets/programme-builder.js` and `assets/authors/` are hand-written or supplied assets.
- `python3 scripts/build-hosting.py` adds every guide, department, skill, template and programme page and the
  downloads, and writes `dist/copilotforge-website.zip` to upload to the web host. See `docs/HOSTING.md`.

Author and contributor details, the tagline and the site address live in `scripts/_site.py`.
