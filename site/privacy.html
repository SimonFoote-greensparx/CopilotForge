Privacy

CopilotForge is a library of skills, programmes, templates and documentation. It does not run a service, and it does not collect, store or send any personal or organisation data.

This website

The website is a set of static pages. It sets no cookies of its own and has no analytics. Our web hosting provider may log requests, such as IP addresses and browser details, to operate and secure the service.

The programme builder

The programme builder runs entirely in your browser. Nothing you type is sent anywhere; the profile file is created on your device when you select Download.

The skills and plugins

The skills are instructions that run inside the Microsoft AI assistant you install them in, such as Microsoft Copilot Cowork. Any data you share in those conversations is processed under that product's terms and your organisation's agreement with Microsoft, not by this project. The tailoring skills write organisation profiles and generated documents only to your own storage, never to this project.
